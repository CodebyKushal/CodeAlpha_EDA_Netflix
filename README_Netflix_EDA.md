# Netflix Movies and TV Shows — Exploratory Data Analysis

## Project Overview
This project explores the Netflix Movies and TV Shows dataset using Python. The goal is to understand the data, identify trends and patterns, check data quality, and communicate findings through visualizations.

## Objectives
- Explore the dataset structure, columns, and data types.
- Identify missing values and duplicate records.
- Compare Movies and TV Shows.
- Analyze release-year trends.
- Explore country and genre distributions.
- Examine movie durations and potential outliers.
- Test a statistical hypothesis.
- Present findings using charts.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

## Dataset
The dataset contains information about Netflix titles, including title, content type, director, country, date added, release year, rating, duration, and genres.

**Dataset source:** [Netflix Movies and TV Shows — Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
